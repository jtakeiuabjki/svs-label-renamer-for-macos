# Security Policy / セキュリティポリシー

## 日本語

### サポート対象

SVS Label Renamer for macOSはベータ版として開発中です。セキュリティ修正は、原則としてこのリポジトリで公開している最新版に対して提供します。過去のバージョンを利用している場合は、最新版で問題が再現するか確認してください。

| バージョン | サポート状況 |
| --- | --- |
| 最新版 | サポート対象 |
| 過去のバージョン | サポート対象外 |

### 脆弱性の報告

セキュリティ上の問題を発見した場合は、公開Issueを作成しないでください。リポジトリの[Security Advisories](https://github.com/jtakeiuabjki/svs-label-renamer-for-macos/security/advisories)を開き、**Report a vulnerability**から非公開で報告してください。

可能な範囲で、次の情報を含めてください。

- 使用したアプリのバージョンとmacOSのバージョン
- 問題を再現するための手順
- 想定される影響
- 個人情報を除いたログまたはスクリーンショット

SVSファイル、スライドラベル、患者情報、病理番号などの機密情報は添付しないでください。個人で運営しているプロジェクトのため返信に時間を要する場合がありますが、受領後できるだけ速やかに確認します。

一般的な不具合や機能提案は、通常の[GitHub Issues](https://github.com/jtakeiuabjki/svs-label-renamer-for-macos/issues)を利用してください。

## English

### Supported versions

SVS Label Renamer for macOS is under active beta development. Security fixes are generally provided only for the latest version published in this repository. If you use an older version, please confirm whether the issue is reproducible with the latest version.

| Version | Supported |
| --- | --- |
| Latest version | Yes |
| Older versions | No |

### Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Open the repository's [Security Advisories](https://github.com/jtakeiuabjki/svs-label-renamer-for-macos/security/advisories) page and use **Report a vulnerability** to submit a private report.

When possible, include:

- The app version and macOS version
- Steps to reproduce the issue
- The potential impact
- Logs or screenshots with personal information removed

Do not attach SVS files, slide-label images, patient information, pathology identifiers, or other sensitive data. This project is maintained by an individual, so responses may occasionally take time, but reports will be reviewed as promptly as possible.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/jtakeiuabjki/svs-label-renamer-for-macos/issues).
